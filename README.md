# CleanX

**Declutter X (Twitter): hide view & engagement counts, streamline navigation, and write distraction-free in Zen mode.**

净化 X（Twitter）界面：隐藏浏览量与互动数字、精简导航与时间线、Zen 专注写作，让 X 更清爽、更专注。

Chrome 扩展 · Chrome Extension — 本仓库是 CleanX 的主页与支持页面（源码见 [cleanX](https://github.com/englishhearhub/cleanX) 仓库）。

---

## Install / 安装

从 Chrome 应用商店安装 / Install from the Chrome Web Store:
👉 https://chromewebstore.google.com/detail/incighicjakhnkaedhagbdoaaoaefimo

已构建版本也可从源码安装 / You can also load the built `dist` folder from the [cleanX](https://github.com/englishhearhub/cleanX) repository.

## Features / 功能

- ✓ 默认简洁版一键净化，自定义版本逐项调整 / One-click clean preset, or fine-tune every option
- ✓ 隐藏浏览量、回复/转推/点赞数、关注人数 / Hide view, reply, repost, like & follower counts
- ✓ 精简时间线：屏蔽推广推文、推荐关注、话题卡片 / Clean timeline: no promoted posts, who-to-follow or topic carousels
- ✓ 自定义导航：15 个侧栏入口独立显隐，可提取到一级侧栏 / Per-item sidebar nav control, plus promoted shortcuts
- ✓ 右侧栏、消息抽屉、Grok 抽屉独立开关 / Independent toggles for right sidebar, message & Grok drawers
- ✓ Zen 专注写作：全屏编辑器，Escape 退出 / Zen writer mode with Escape to exit
- ✓ 浅色 / 深色界面外观，跟随系统 / Light & dark UI, follows system theme
- ✓ 自定义 CSS、配置导入导出 / Custom CSS, config import & export
- ✓ 无遥测、无追踪，全部设置只保存在本机 / No telemetry or tracking; settings stay on your device
